## Features

- Easy configuration
- TypeScript
- Built-in authentication with configurable better-auth.
- Auto-generated:
  - API endpoints
  - Types
  - Database schema
  - Admin panel
- SQLite database (drizzle)
- Live Edit system
- Media management
- Fine grained access control
- i18n support
- Document versions
- Optional SMTP integration
- Many built-in fields type
